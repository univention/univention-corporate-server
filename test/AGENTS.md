# test/

Integration tests, end-to-end tests, CI/CD scenario configurations, and test utilities for UCS. See `test/README.md` for an overview of all CI/CD test scenarios.

## Subdirectories

| Directory | Description |
|---|---|
| [generate-appliance](generate-appliance/AGENTS.md) | Virtual appliance image generator (KVM, VMware, ESX, VirtualBox) |
| [product-tests](product-tests/AGENTS.md) | Pre-release integration test configurations |
| [scenarios](scenarios/AGENTS.md) | CI scenario `.cfg` files for Jenkins |
| [ucs-gui-tests](ucs-gui-tests/AGENTS.md) | GUI installation tests (pytest) |
| [ucs-test](ucs-test/AGENTS.md) | Primary test framework and test suite (~40 binary packages) |
| [ucs-test-tools](ucs-test-tools/AGENTS.md) | Development and testing tool collection |
| [univention-demo-configuration](univention-demo-configuration/AGENTS.md) | Demo environment configuration |
| [utils](utils/AGENTS.md) | CI/CD shell and Python utility scripts |
