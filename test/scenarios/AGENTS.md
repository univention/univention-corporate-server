# scenarios

Collection of `.cfg` scenario configuration files for multi-environment CI test setups on Jenkins.

## Key contents
- `autotest-*.cfg` -- Scenario configs for automated tests (update, install, UCS@school, etc.)
- `ad-connector/`, `s4-connector/` -- AD/S4 connector test scenarios
- `install-testing/`, `update-testing/`, `setup-testing/` -- Installation and update test scenarios
- `kvm-templates/` -- KVM template configurations
- `base/`, `umc/`, `keycloak/` -- Subsystem-specific scenario directories
- `ucsschool-performance-*.cfg` -- UCS@school performance test scenarios
