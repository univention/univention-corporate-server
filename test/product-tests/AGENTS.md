# product-tests

Pre-release integration test configurations covering multiple UCS subsystems.

## Key contents
- `appcenter/` -- App Center integration tests
- `base/` -- Base system tests (LDAP, SAML, listener)
- `samba/` -- Samba/AD integration tests
- `umc/` -- UMC (Univention Management Console) tests
- `domain-join/` -- Domain join tests
- `component/` -- Component-level tests
- `ucsschool/` -- UCS@school integration tests
