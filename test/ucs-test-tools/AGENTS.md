# test/ucs-test-tools/

Debian source package. A small tool collection for UCS development and testing.

## Binary packages

- **ucs-test-tools** -- Helper tools and scripts for testing UCS installations. Depends on `shell-univention-lib` and `univention-directory-manager-tools`.

## Structure

- `usr/sbin/` -- System administration helper scripts.
- `usr/share/` -- Shared data and utility files.
- `debian/` -- Debian packaging files.
