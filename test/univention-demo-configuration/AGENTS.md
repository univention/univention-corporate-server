# test/univention-demo-configuration/

Debian source package. Provides a restricted configuration for the demo.univention.de environment.

## Binary packages

- **univention-demo-configuration** -- Installs demo-specific UCR settings, portal customization, and sample data.

## Structure

- `conffiles/` -- UCR template files for demo configuration.
- `data/` -- Sample/demo data.
- `portal/` -- Portal customization for the demo instance.
- `usr/` -- Installed scripts and resources.
- `debian/` -- Debian packaging files.
