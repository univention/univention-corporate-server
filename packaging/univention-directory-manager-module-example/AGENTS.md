# univention-directory-manager-module-example

Example UDM (Univention Directory Manager) module demonstrating how to manage custom LDAP objects (IP phones). Serves as a reference for developers creating their own UDM modules.

## Binary Packages

- `univention-directory-manager-module-example` -- UDM module for managing example IP phone objects
- `univention-directory-manager-module-example-schema` -- LDAP schema for the example module

## Directory Structure

- `modules/` -- UDM module Python code
- `schema/` -- LDAP schema definitions
- `conffiles/` -- UCR template configuration files
- `scripts/` -- Helper scripts
