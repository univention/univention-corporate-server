# univention-package-template

Template/scaffold for creating new UCS Debian packages. Demonstrates the standard structure including UCR templates, join scripts, and debian packaging.

## Binary Packages

- `univention-package-template` -- Example package built from the template
- `univention-package-template-test` -- Companion test package

## Directory Structure

- `conffiles/` -- UCR template configuration files
- `76univention-package-template.inst` -- Example join script
- `template-tool` -- Example tool/script
