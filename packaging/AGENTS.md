# packaging/

Tools and templates for building UCS Debian packages. Contains linting, debhelper extensions, localization tools, test helpers, and example packages.

## Subdirectories

| Directory | Description |
|---|---|
| [ucslint](ucslint/AGENTS.md) | Linter for UCS Debian source packages |
| [univention-debhelper](univention-debhelper/AGENTS.md) | Helper programs for debian/rules |
| [univention-directory-manager-module-example](univention-directory-manager-module-example/AGENTS.md) | Example UDM module (IP phones) |
| [univention-l10n](univention-l10n/AGENTS.md) | Localization build tools |
| [univention-package-template](univention-package-template/AGENTS.md) | Debian package template |
| [univention-package-template-python](univention-package-template-python/AGENTS.md) | Python module package template |
| [univention-unittests](univention-unittests/AGENTS.md) | Pytest plugins for UCS packages |
