# univention-directory-reports

Generates PDF reports for UDM objects using RML or LaTeX template files with a special template syntax for LDAP attributes.

## Binary packages

- `univention-directory-reports` -- Report generator
- `python3-univention-directory-reports` -- Python library (RML/PDF)
- `univention-directory-reports-latex` -- LaTeX-based report templates

## Directory structure

- `modules/` -- Python modules (`univention.directory.reports`)
- `templates/` -- Report template files (RML, LaTeX)
- `conffiles/` -- UCR templates
- `man/` -- Man pages
- `test/` -- Tests
- `debian/` -- Debian packaging
