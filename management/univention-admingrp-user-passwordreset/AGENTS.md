# univention-admingrp-user-passwordreset

LDAP ACLs that grant password reset ability to a special helpdesk user group.

## Binary packages

- `univention-admingrp-user-passwordreset`

## Directory structure

- `conffiles/` -- UCR templates for LDAP ACL configuration
- `ldap-group-to-file-hooks.d/` -- Hook scripts for group-to-file mapping
- `95univention-admingrp-user-passwordreset.inst` -- Join script
- `debian/` -- Debian packaging
