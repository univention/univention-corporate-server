# univention-system-info

Collects system hardware and software information, with a UMC module for viewing and uploading system info.

## Binary packages

- `univention-system-info` -- CLI system info collection script
- `univention-management-console-module-sysinfo` -- UMC module for system info

## Directory structure

- `univention-system-info` -- CLI collection script
- `umc/` -- UMC module (Python backend + JS frontend)
- `debian/` -- Debian packaging
