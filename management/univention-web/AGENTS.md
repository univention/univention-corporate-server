# univention-web

UMC JavaScript library, CSS/style theme, and web frontend build infrastructure. Built on Dojo Toolkit with Node.js/Stylus tooling.

## Binary packages

- `univention-web-js` -- Compiled UMC JavaScript library
- `univention-web-style` -- CSS and graphic theme data
- `univention-web-src` -- Uncompressed JS source files

## Directory structure

- `js/` -- JavaScript source modules (`umc/`, `management/`)
- `css/` -- Stylus/CSS stylesheets
- `icons/` -- Icon assets
- `conffiles/` -- UCR templates
- `tests/` -- Frontend tests
- `docs/` -- Documentation
- `Makefile` -- Build logic
- `package.json` -- Node.js dependencies
- `debian/` -- Debian packaging
