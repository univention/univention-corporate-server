# univention-management-console-module-udm

UMC module for UCS Directory Manager (UDM), providing a web UI for managing LDAP objects (users, groups, computers, etc.).

## Binary packages

- `univention-management-console-module-udm`

## Directory structure

- `umc/` -- UMC module (Python backend + JS frontend)
- `conffiles/` -- UCR templates
- `univention-directory-reports-cleanup` -- Report cleanup script
- `debian/` -- Debian packaging
