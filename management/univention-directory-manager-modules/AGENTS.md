# univention-directory-manager-modules

Debian source package: Modules for UCS Directory Manager (UDM). Python 3 modules implementing UDM features.

## Key contents
- `univention.admin` Python module (core UDM logic, handlers, syntax, policies)
- `univention.udm` Python module (simplified UDM API)
- `univention.admincli` Python module (UDM CLI interface)
- UDM object type handlers for users, groups, computers, DNS, DHCP, etc.
