# univention-dojo

Dojo Toolkit JavaScript source files used by the UMC web frontend, including UCS-specific patches.

## Binary packages

- `univention-dojo` -- Dojo Toolkit JS source files
- `univention-dojo-dev` -- Build utilities and tools

## Directory structure

- `fix_*.patch` -- UCS-specific patches for Dojo/dgrid/dijit
- `dompurify.js` -- DOMPurify library
- `Makefile` -- Build logic (downloads and patches Dojo)
- `debian/` -- Debian packaging
