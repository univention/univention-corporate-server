# univention-join

Domain join tools allowing UCS computers to join and participate in a UCS domain.

## Binary packages

- `univention-join` -- Join scripts and tools
- `univention-join-dev` -- Development files for packages using univention-join

## Directory structure

- `univention-join` -- Main join script
- `univention-server-join` -- Server join script
- `univention-run-join-scripts` -- Run pending join scripts
- `joinscripthelper.lib` -- Shell library for join script helpers
- `conffiles/` -- UCR templates
- `debian/` -- Debian packaging
