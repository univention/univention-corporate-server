# monitoring/

Monitoring packages for UCS. Contains Nagios plugins and a monitoring client for checking RAID, SMART, Samba, CUPS, and connector status.

## Subdirectories

| Directory | Description |
|---|---|
| [univention-monitoring-client](univention-monitoring-client/AGENTS.md) | Monitoring client package |
| [univention-nagios](univention-nagios/AGENTS.md) | Nagios client support |
| [univention-nagios-ad-connector](univention-nagios-ad-connector/AGENTS.md) | Transitional package |
| [univention-nagios-raid](univention-nagios-raid/AGENTS.md) | Software RAID monitoring plugin |
| [univention-nagios-s4-connector](univention-nagios-s4-connector/AGENTS.md) | S4 Connector monitoring plugin |
| [univention-nagios-samba](univention-nagios-samba/AGENTS.md) | Samba state monitoring plugins |
| [univention-nagios-servicechecks](univention-nagios-servicechecks/AGENTS.md) | CUPS/web service monitoring plugin |
| [univention-nagios-smart](univention-nagios-smart/AGENTS.md) | SMART disk health monitoring plugin |
