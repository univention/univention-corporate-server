# Monitoring

Nagios-based monitoring plugins and client packages for checking RAID, SMART, Samba, CUPS, and connector status in UCS. All subdirectories are Debian source packages.

## Packages

- [univention-monitoring-client/AGENTS.md](univention-monitoring-client/AGENTS.md) -- Monitoring client, plugins, and alert definitions for various UCS services.
- [univention-nagios/AGENTS.md](univention-nagios/AGENTS.md) -- Nagios client and common support (NRPE, listener modules).
- [univention-nagios-ad-connector/AGENTS.md](univention-nagios-ad-connector/AGENTS.md) -- Transitional dummy package (AD connector monitoring moved to univention-monitoring-client).
- [univention-nagios-raid/AGENTS.md](univention-nagios-raid/AGENTS.md) -- Nagios plugin for software RAID status monitoring.
- [univention-nagios-s4-connector/AGENTS.md](univention-nagios-s4-connector/AGENTS.md) -- Nagios plugin for Samba/S4 connector state monitoring.
- [univention-nagios-samba/AGENTS.md](univention-nagios-samba/AGENTS.md) -- Nagios plugin for Samba DRS replication failure monitoring.
- [univention-nagios-servicechecks/AGENTS.md](univention-nagios-servicechecks/AGENTS.md) -- Nagios plugins for CUPS, Squid, and OPSI service monitoring.
- [univention-nagios-smart/AGENTS.md](univention-nagios-smart/AGENTS.md) -- Nagios plugin for SMART hard disk status monitoring.
