# univention-pkgdb

Debian source package: Software monitoring database. Server-side components for the UCS package database.

## Key contents
- `pyshared/` -- Python library for package database access
- `pkgdb.py`, `pkgdb-watch.py` -- LDAP listener modules
- `umc/` -- UMC module for package database browsing
- `sql/` -- database schema and SQL scripts
- `univention-pkgdb-scan`, `univention-pkgdb-check` -- CLI tools
- `conffiles/` -- UCR template files
