# univention-samba

Debian source package: Samba Member Server. Authentication, file and print services for Windows.

## Key contents
- `python/` -- Python library code
- `samba-shares.py`, `samba-privileges.py` -- LDAP listener modules
- `scripts/` -- helper scripts
- `conffiles/` -- UCR template files for Samba configuration
- `examples/` -- example configuration files
- `server_password_change.d/` -- hooks for server password rotation
