# univention-ldb-modules

Debian source package: Univention LDB modules. UCS specific LDB modules.

## Key contents
- `modules/` -- C source for LDB modules
- `tests/` -- module tests
- `third_party/` -- vendored dependencies
- `wscript` -- WAF build script
- `Makefile`, `configure`, `buildtools/` -- build system files
- `ucs-school-create_windows_computer` -- helper script for UCS@school
