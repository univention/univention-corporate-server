# univention-apache

Provides the UCS-specific Apache2 web server configuration and a tool for managing virtual hosts.

## Binary Packages

- `univention-apache` -- main Apache2 configuration with PAM auth module
- `univention-apache-vhost` -- virtual host management tool

## Directory Structure

- `conffiles/` -- UCR templates for Apache configuration files
- `www/` -- static web content
- `univention-add-vhost` -- script to add virtual hosts
