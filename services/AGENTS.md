# services/

Network service packages for UCS. Contains Debian source packages for DNS, DHCP, LDAP connectors (AD and Samba4), Samba, RADIUS, Apache, NFS, databases, printing, and more.

## Subdirectories

| Directory | Description |
|---|---|
| [univention-ad-connector](univention-ad-connector/AGENTS.md) | Active Directory Connector synchronisation |
| [univention-admin-diary](univention-admin-diary/AGENTS.md) | Admin Diary backend |
| [univention-apache](univention-apache/AGENTS.md) | Apache2 web server configuration |
| [univention-bind](univention-bind/AGENTS.md) | DNS server (LDAP/Samba4 backend) |
| [univention-dhcp](univention-dhcp/AGENTS.md) | DHCP server (LDAP backend) |
| [univention-keycloak](univention-keycloak/AGENTS.md) | Keycloak IdP integration |
| [univention-ldb-modules](univention-ldb-modules/AGENTS.md) | UCS-specific LDB modules |
| [univention-mariadb](univention-mariadb/AGENTS.md) | MariaDB configuration |
| [univention-nfs](univention-nfs/AGENTS.md) | NFS server configuration |
| [univention-pkgdb](univention-pkgdb/AGENTS.md) | Software monitoring / package database |
| [univention-postgresql](univention-postgresql/AGENTS.md) | PostgreSQL configuration |
| [univention-printserver](univention-printserver/AGENTS.md) | Print server (UDM-managed) |
| [univention-radius](univention-radius/AGENTS.md) | FreeRADIUS 802.1X integration |
| [univention-s4-connector](univention-s4-connector/AGENTS.md) | Samba4 Connector synchronisation |
| [univention-samba](univention-samba/AGENTS.md) | Samba Member Server |
| [univention-samba4](univention-samba4/AGENTS.md) | Samba4 integration |
| [univention-sasl](univention-sasl/AGENTS.md) | SASL2 configuration |
| [univention-squid](univention-squid/AGENTS.md) | Squid web proxy integration |
| [univention-squid-kerberos](univention-squid-kerberos/AGENTS.md) | Kerberos auth for Squid proxy |
| [univention-tftp](univention-tftp/AGENTS.md) | TFTP server for network booting |
