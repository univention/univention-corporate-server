# univention-keycloak

Client-side integration for the Keycloak identity provider. Provides scripts to configure Keycloak OIDC/SAML clients, authentication flows, and federation with UCS LDAP.

## Binary Packages

- `univention-keycloak-client` -- Keycloak client configuration scripts

## Directory Structure

- `scripts/` -- Keycloak configuration and management scripts
- `49univention-keycloak-client.inst` -- join script
