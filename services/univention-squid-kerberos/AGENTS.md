# univention-squid-kerberos

Adds Kerberos (negotiate) authentication to the Squid web proxy using Samba4 as the backend.

## Binary Packages

- `univention-squid-kerberos` -- Kerberos authentication configuration for Squid

## Directory Structure

- `98univention-squid-samba4.inst` -- join script for Kerberos keytab setup
