# univention-squid

Debian source package: Squid web proxy integration into UCS.

## Key contents
- `conffiles/` -- UCR template files for Squid configuration
- `basic_ldap_auth_encoding_wrapper` -- wrapper for LDAP authentication
- `squid_ldap_ntlm_auth` -- NTLM authentication helper
- `squid-pw-rotate` -- password rotation script
- `local_bottom.conf`, `local_rules.conf` -- local configuration overrides
