# univention-dhcp

Debian source package: DHCP server using LDAP for configuration.

## Key contents
- `dhcp.py` -- LDAP listener module for DHCP configuration
- `conffiles/` -- UCR template files for DHCP configuration
- `import-dhcpd.conf` -- script to import existing dhcpd.conf
- `univention-dhcp.conf` -- default configuration
- `etc/`, `usr/` -- additional installed files
