# univention-dhcp

Integrates the ISC DHCP server into UCS with LDAP-based configuration.

## Binary Packages

- `univention-dhcp` -- DHCP server configuration, join script, listener module

## Directory Structure

- `conffiles/` -- UCR templates for DHCP configuration
- `dhcp.py` -- directory listener module
- `etc/` -- additional configuration files
- `usr/` -- helper utilities
- `import-dhcpd.conf` -- configuration import script
