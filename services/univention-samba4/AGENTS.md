# univention-samba4

Debian source package: Samba4 integration. Scripts and patches for Samba4 integration into UCS.

## Key contents
- `samba-shares.py`, `samba4-idmap.py` -- LDAP listener modules
- `sbin/`, `scripts/` -- administration and helper scripts
- `lib/` -- shell library functions
- `conffiles/` -- UCR template files for Samba4 configuration
- `pam_univentionsambadomain.c` -- PAM module source
- `sysvol-sync-scripts/` -- SYSVOL replication scripts
- `univention-s4search`, `s4search-decode` -- Samba4 LDAP search tools
