# univention-admin-diary

Debian source package: Univention Admin Diary backend.

## Key contents
- `python/` -- Python library code
- `listener/` -- LDAP listener module
- `umc/` -- UMC module for Admin Diary
- `create-database`, `create-tables` -- database setup scripts
- `admindiary_backend_wrapper.py` -- backend wrapper script
- `conffiles/` -- UCR template files
