# univention-bootsplash

Graphical boot screen (Plymouth theme) and post-boot welcome screen for UCS.

## Binary Packages

- `univention-bootsplash` -- Plymouth boot splash configuration
- `univention-welcome-screen` -- welcome screen shown after system startup

## Key Directories

- `conffiles/` -- UCR templates
- `ucs/`, `ucs-light/` -- Plymouth theme assets
- `sprites/` -- graphical sprite assets
- `i18n/` -- translations
- `systemd/` -- systemd service files
