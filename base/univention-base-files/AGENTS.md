# univention-base-files

Base configuration files for UCS and a metapackage pulling in default system packages.

## Binary Packages

- `univention-base-files` -- base configuration (UCR templates, scripts)
- `univention-base-packages` -- metapackage depending on default UCS packages

## Key Directories

- `conffiles/` -- UCR templates for base system config files
- `scripts/` -- helper scripts
- `tests/` -- test suite
- `univention-directory-policy/` -- directory policy scripts
- `etc/` -- static config file snippets
