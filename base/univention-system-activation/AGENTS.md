# univention-system-activation

Web service for system activation of UCS virtual appliance images. Provides a WSGI-based web interface for license activation.

## Binary Packages

- `univention-system-activation`

## Key Directories

- `src/` -- Python WSGI application source
- `www/` -- web frontend assets
- `scripts/` -- helper scripts
- `conffiles/` -- UCR templates (Apache config)
- `tests/` -- test suite
