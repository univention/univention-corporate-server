# univention-policy

LDAP group policy library and tools. Reads and evaluates group policies stored in LDAP.

## Binary Packages

- `libunivention-policy0` -- C shared library
- `libunivention-policy-dev` -- development headers
- `univention-policy-tools` -- `univention_policy_result` CLI tool

## Key Directories

- `lib/` -- C library source (autotools)
- `include/` -- C header files
- `python-lib/` -- Python helper library
- `tools/` -- CLI tools
- `doc/` -- documentation

## Notes

- Built with autotools (`configure.in`, `Makefile.am`)
