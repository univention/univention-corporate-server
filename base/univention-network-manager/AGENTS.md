# univention-network-manager

Network configuration tools for UCS (bridges, VLANs, bonding, DHCP).

## Binary Packages

- `univention-ifplugd` -- transitional dummy package
- `univention-network-common` -- network tools and configuration

## Key Files

- `conffiles/` -- UCR templates for network interface configuration
- `etc/` -- default config files
- `univention-register-network-address` -- network address registration script
