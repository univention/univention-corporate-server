# univention-config-registry

Debian source package: Transitional package for base configuration. Base configuration files moved to univention-base-files. Contains the Univention Config Registry (UCR) Python library.

Contains Python code: `setup.cfg` defines the `univention.config_registry` Python package.

## Key contents
- `debian/` -- Debian packaging files
- `setup.cfg` -- Python package configuration
- `univention/config_registry/` -- UCR Python library
