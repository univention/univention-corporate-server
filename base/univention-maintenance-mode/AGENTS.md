# univention-maintenance-mode

Minimal web server displayed during release updates when Apache/UMC are unavailable.

## Binary Packages

- `univention-maintenance-mode`

## Key Files

- `index.html` -- maintenance mode web page
- `univention-maintenance-mode.service` -- systemd service
- `univention-maintenance-mode-update-progress` -- update progress script
- `conffiles/` -- UCR templates
