# univention-ipcalc

IP address and network calculation tool for UCS.

## Binary Packages

- `univention-ipcalc` -- CLI tool
- `python3-univention-ipcalc` -- Python 3 library

## Key Directories

- `univention/` -- Python package source
- `tests/` -- pytest test suite
- `setup.py`, `setup.cfg` -- setuptools configuration
