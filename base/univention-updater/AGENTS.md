# univention-updater

Debian source package: System upgrading tool. Handles UCS release updates, errata updates, and component management.

Contains Python code: `setup.py` and `setup.cfg` install the `univention.updater` Python package.

## Key contents
- `debian/` -- Debian packaging files
- `setup.py`, `setup.cfg` -- Python package configuration
- `univention/updater/` -- Python modules for update management
