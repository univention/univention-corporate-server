# univention-lib

Common scripting libraries (Python and shell) used by various UCS components.

## Binary Packages

- `python3-univention-lib` -- Python 3 library (`univention.lib`)
- `shell-univention-lib` -- shell function library

## Key Directories

- `python/` -- Python modules (DNS, LDAP, APT, Samba, image handling, etc.)
- `shell/` -- shell library scripts
- `unittests/` -- unit tests
