# univention-group-membership-cache

Local cache for user and group membership (including nested groups) to avoid frequent LDAP queries.

## Binary Packages

- `univention-group-membership-cache` -- cache management
- `python3-univention-group-membership-cache` -- Python 3 library

## Key Directories

- `src/` -- Python source modules
- `unittest/` -- unit tests

## Key Files

- `univention-ldap-cache` -- cache management script
