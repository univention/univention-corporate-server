# univention-debug-python

Debian source package: Debugging and logging library (Python 3 interface). Provides the Python bindings for the univention-debug C library.

Contains Python code: `setup.py` builds and installs the Python interface.

## Key contents
- `debian/` -- Debian packaging files
- `setup.py` -- Python package build configuration
- Python C extension wrapping the univention-debug library
