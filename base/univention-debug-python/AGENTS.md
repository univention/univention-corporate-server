# univention-debug-python

Python 3 bindings for the UCS debugging/logging library (`libunivention-debug`). Integrates with Python's logging via `logfmter`.

## Binary Packages

- `python3-univention-debug` (Architecture: any -- C extension)

## Key Directories

- `python/` -- Python module source
- `tests/` -- pytest test suite
- `setup.py` -- setuptools config
