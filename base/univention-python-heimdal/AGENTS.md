# univention-python-heimdal

Python 3 bindings for the Heimdal Kerberos library. Provides access to keytabs, credentials, principals, and encryption types.

## Binary Packages

- `python3-univention-heimdal` (Architecture: any -- C extension)

## Key Files

- `*.c`, `*.h` -- C extension source files (principal, keytab, ccache, creds, salt, ticket, etc.)
- `module.c` -- Python module initialization
- `setup.py` -- build configuration
- `test.py` -- test script
