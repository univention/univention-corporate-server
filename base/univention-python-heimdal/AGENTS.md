# univention-python-heimdal

Debian source package: Kerberos interface module for Python 3. Provides Heimdal library bindings for Python.

Contains Python code: `setup.py` builds and installs the Python C extension.

## Key contents
- `debian/` -- Debian packaging files
- `setup.py` -- Python package build configuration
- Python C extension wrapping the Heimdal Kerberos library
