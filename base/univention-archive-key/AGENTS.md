# univention-archive-key

APT archive signing keys for Univention Corporate Server repositories (3.x, 4.x, 5.x).

## Binary Packages

- `univention-archive-key` -- full GPG keyring
- `univention-archive-key-udeb` -- minimal form for the Debian installer

## Key Files

- `univention-archive-key-ucs-*.gpg` -- GPG keyring files for each UCS major version
