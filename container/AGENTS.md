# Container Packages

Docker container integration packages for UCS. All subdirectories are Debian source packages.

- [univention-appliance-docker-container/AGENTS.md](univention-appliance-docker-container/AGENTS.md) -- Appliance setup settings for running UCS inside a Docker container.
- [univention-docker-container-mode/AGENTS.md](univention-docker-container-mode/AGENTS.md) -- Transitional (dummy) package, can be removed.
- [univention-docker/AGENTS.md](univention-docker/AGENTS.md) -- Configuration adjustments for running Docker on a UCS host.
