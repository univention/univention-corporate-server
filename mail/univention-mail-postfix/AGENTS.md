# univention-mail-postfix

Debian source package: Postfix configuration. Basic configuration for the postfix mail transport agent.

## Key contents
- `conffiles/` - UCR templates for postfix configuration files
- `hosteddomains.py` - UCR module for hosted domain management
- `etc/postfix/` - Postfix configuration resources
- `67univention-mail-server.inst` - Join script for mail server setup
- `dh_512.pem`, `dh_2048.pem` - Diffie-Hellman parameter files for TLS
- `share/`, `usr/` - Additional resources and scripts
