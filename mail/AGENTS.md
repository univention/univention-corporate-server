# Mail Packages

Mail stack packages for UCS: Postfix MTA, Dovecot IMAP/POP3, anti-virus (ClamAV/amavis), anti-spam (SpamAssassin), greylisting (Postgrey), fetchmail, and canonical maps. All subdirectories are Debian source packages.

- [univention-antivir-mail/AGENTS.md](univention-antivir-mail/AGENTS.md) -- Anti-virus mail scanning via amavisd-new and ClamAV.
- [univention-fetchmail/AGENTS.md](univention-fetchmail/AGENTS.md) -- Remote mail retrieval (fetchmail) with UDM/LDAP integration.
- [univention-mail-canonical-maps/AGENTS.md](univention-mail-canonical-maps/AGENTS.md) -- UDM extended attributes for Postfix canonical maps.
- [univention-mail-dovecot/AGENTS.md](univention-mail-dovecot/AGENTS.md) -- Dovecot IMAP/POP3/LMTP/Sieve server configuration.
- [univention-mail-postfix/AGENTS.md](univention-mail-postfix/AGENTS.md) -- Postfix mail transport agent configuration.
- [univention-postgrey/AGENTS.md](univention-postgrey/AGENTS.md) -- Postfix greylisting via Postgrey.
- [univention-spamassassin/AGENTS.md](univention-spamassassin/AGENTS.md) -- Anti-spam protection via SpamAssassin.
