# mail/

Mail service packages for UCS. Contains Debian source packages for Postfix (MTA), Dovecot (IMAP), fetchmail, spam filtering, antivirus, and greylisting.

## Subdirectories

| Directory | Description |
|---|---|
| [univention-antivir-mail](univention-antivir-mail/AGENTS.md) | Antivirus mail configuration |
| [univention-fetchmail](univention-fetchmail/AGENTS.md) | Fetchmail integration with UDM |
| [univention-mail-canonical-maps](univention-mail-canonical-maps/AGENTS.md) | Canonical maps for mail via UDM |
| [univention-mail-dovecot](univention-mail-dovecot/AGENTS.md) | Dovecot IMAP configuration |
| [univention-mail-postfix](univention-mail-postfix/AGENTS.md) | Postfix MTA configuration |
| [univention-postgrey](univention-postgrey/AGENTS.md) | Postfix greylisting (postgrey) |
| [univention-spamassassin](univention-spamassassin/AGENTS.md) | SpamAssassin antispam configuration |
