# univention-postgrey

UCS greylisting configuration for Postfix via Postgrey. Adds client whitelist definitions and UCR-managed configuration on top of the standard postgrey package.

## Binary Packages

- `univention-postgrey`

## Directory Structure

- `conffiles/` -- UCR templates for Postgrey configuration and whitelists.
- `debian/` -- Debian packaging, UCR variable definitions.
