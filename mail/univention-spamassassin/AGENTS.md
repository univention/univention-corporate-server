# univention-spamassassin

UCS anti-spam protection via SpamAssassin. Provides UCR-managed configuration for the SpamAssassin daemon and spamc client.

## Binary Packages

- `univention-spamassassin`

## Directory Structure

- `conffiles/` -- UCR templates for SpamAssassin configuration (`etc/`, `usr/`).
- `debian/` -- Debian packaging, UCR variable definitions.
