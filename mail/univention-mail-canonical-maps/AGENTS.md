# univention-mail-canonical-maps

UDM extended attributes for managing Postfix canonical maps. Allows address rewriting rules to be stored in LDAP and managed through UDM.

## Binary Packages

- `univention-mail-canonical-maps`

## Directory Structure

- `92univention-mail-canonical-maps.inst` -- Join script registering UDM extended attributes.
- `debian/` -- Debian packaging.
