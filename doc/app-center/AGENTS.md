# App Center Documentation

Guide for app providers who want to publish applications on the Univention App Center. Covers app packaging, configuration, lifecycle management, and appliance builds.

## Format

Sphinx RST (`index.rst`, `conf.py`).

## Build

```sh
make html      # Build HTML
make latexpdf  # Build PDF
make spelling  # Spell check
```

Uses the Sphinx Docker image from the parent `doc/Makefile`.
