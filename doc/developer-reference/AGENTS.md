# developer-reference

Developer guide for extending UCS (packaging, UDM, UCR, UMC, LDAP, listeners, join scripts).

## Key contents
- `index.rst` -- Documentation entry point
- `packaging.rst`, `packaging/` -- Debian packaging guide for UCS
- `udm/` -- UDM (Univention Directory Manager) extension docs
- `ucr/` -- UCR (Univention Configuration Registry) docs
- `umc/` -- UMC (Univention Management Console) module development
- `listener/` -- Directory listener module development
- `join/` -- Join script development
- `ldap.rst` -- LDAP integration guide
- `conf.py`, `Makefile` -- Sphinx build configuration
