# Debian/Ubuntu Administrators Guide

Guide for system administrators with Debian/Ubuntu background transitioning to UCS. Covers differences in domain management, software management, and system configuration.

## Format

Sphinx RST (`index.rst`, `conf.py`).

## Build

```sh
make html      # Build HTML
make spelling  # Spell check
```

Uses the Sphinx Docker image from the parent `doc/Makefile`.
