.. _ext-dom-ubuntu:

***********************************************
Integration of Ubuntu clients into a UCS domain
***********************************************

Univention Corporate Server allows the integration of Ubuntu clients. You could
refer to :ref:`ext-dom-unix` and adapt the general approach to Ubuntu. But for
Ubuntu, Univention provides an easy tool for the domain join into UCS:
`<https://help.ubuntu.com/community/LDAPClientAuthentication>`_. Pleae refer to
the project's documentation.
