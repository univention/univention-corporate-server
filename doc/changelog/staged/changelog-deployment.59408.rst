The package sources of UCS and of enabled components are now written in the DEB822 format to :file:`/etc/apt/sources.list.d/15_ucs-online-version.sources` and :file:`/etc/apt/sources.list.d/20_ucs-online-component.sources`. During the update to UCS 5.3, entries in :file:`/etc/apt/sources.list` are moved to :file:`/etc/apt/sources.list.d/moved-from-main.sources` and the original file is kept as :file:`/etc/apt/sources.list.upgrade530.bak`. The migration can be skipped by setting the |UCSUCRV| ``update53/skip/sources-migration`` to ``yes``. The file :file:`/etc/apt/mirror.list` for repository mirrors keeps the one-line format required by :program:`apt-mirror`.
