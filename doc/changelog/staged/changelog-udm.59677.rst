Univention Directory Manager now strictly requires LDAP connections to use ``univention.admin.uldap.access`` instead of ``univention.uldap.access``. This ensures that the required authorization checks and exception handling are applied, particularly when using delegated administration. Passing an incompatible LDAP connection now always raises a ``TypeError`` instead of issuing a deprecation warning. The UCR variable ``directory/manager/type-checking/strict`` is no longer required.
