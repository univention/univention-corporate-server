# doc/

Product documentation for UCS, built with Sphinx. See `doc/README.md` for build instructions (`make html`, `make latexpdf`, `make spelling`). English is the default language; German translations use PO files. Published at https://docs.software-univention.de/

Errata advisories (YAML files) are stored under `doc/errata/`.
