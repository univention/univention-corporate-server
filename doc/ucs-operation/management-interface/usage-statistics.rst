Usage statistics
================

Univention collects anonymous usage statistics about the *Management UI*
when you use the *Core Edition* of Nubus for UCS.
Univention uses these statistics to evaluate Nubus for UCS.
For more information about the collected data,
see :uv:kb:`Data collection in Univention Corporate Server <6701>`.
