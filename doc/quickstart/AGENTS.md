# Quickstart Guide

Short introduction for getting started with UCS. Covers downloading, installing, and first steps with UCS including basic domain setup. German translation available via `locales/`.

## Format

Sphinx RST (`index.rst`, `conf.py`).

## Build

```sh
make html      # Build HTML
make spelling  # Spell check
```

Uses the Sphinx Docker image from the parent `doc/Makefile`.
