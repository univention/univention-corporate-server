Sphinx-based architecture documentation for UCS.

- `index.rst` -- Documentation entry point
- `components/` -- Architecture of individual UCS components
- `services/` -- Service-level architecture descriptions
- `concepts/` -- Core architectural concepts
- `positioning.rst` -- Product positioning context
- `bibliography.bib` -- Reference bibliography
- `conf.py`, `Makefile` -- Sphinx build configuration
