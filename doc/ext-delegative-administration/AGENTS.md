# Extended Docs: Delegative Administration

Documentation for the delegative administration feature (experimental). Covers concepts, setup, configuration, object dependencies, and troubleshooting for delegated admin in Univention Nubus.

## Format

Sphinx RST (`index.rst`, `conf.py`).

## Build

```sh
make html      # Build HTML
make spelling  # Spell check
```

Uses the Sphinx Docker image from the parent `doc/Makefile`.
